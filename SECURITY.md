# Security policy

`ts_grants` makes access decisions, so a flaw in it can expose the services
behind it. Please report suspected vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public
issue.

Include the Caddy, caddy-tailscale and caddy-ts-grants versions, the relevant
part of your Caddyfile and policy file (with your own names replaced), and the
request that was allowed or denied wrongly.

Fixes are released for the latest version only.
